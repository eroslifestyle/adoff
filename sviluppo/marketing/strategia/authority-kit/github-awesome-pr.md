## Corpo PR

Hi! Adding [AdOff](https://adoff.app/) — a Manifest V3 ad blocker for Chrome, Edge, Brave, Opera, Firefox and Safari.

What it brings that existing entries in this list don't cover:

- **Stealth anti-detection built in** — defeats anti-adblock walls (sites that detect uBlock Origin or AdBlock Plus don't detect AdOff).
- **Universal video-ad neutralization** — an IMA SDK stub that resumes playback immediately on any player using the Google IMA SDK (no pre-roll, no re-buffering).
- **Zero data collection** — no telemetry, no tracking, no remote logging.
- **100% free** — all features included, no paid plans.

Open-core repo: https://github.com/eroslifestyle/adoff
