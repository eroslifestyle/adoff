## Universal profile (riusabile su tutti)

**Product name:** AdOff

**Tagline:** Stealth ad blocker that anti-adblock walls can't detect — free for everyone.

**Short description:**
AdOff is a Manifest V3 browser extension that blocks ads on every website while staying invisible to anti-adblock detection. It combines 190 network rules, native CSS hiding, a universal video-ad stub, and built-in Stealth Mode anti-detection. 100% free, all features included, zero data collection.

**Long description:**
AdOff blocks ads on every website and on every major browser — Chrome, Edge, Brave, Opera, Firefox and Safari. Four layers do the work: 190 declarativeNetRequest network rules, CSS cosmetic filtering, a universal IMA SDK stub that neutralizes video ads on any player using Google's IMA SDK, and a Stealth Mode that defeats anti-adblock detection.

The stealth layer is the differentiator: sites that fingerprint uBlock Origin or AdBlock Plus typically don't detect AdOff. Video ads are skipped without re-buffering or quality loss, with playback state preserved. Privacy is absolute — no telemetry, no tracking, no remote logging, no data collected. The UI ships in 15 languages.

AdOff is 100% free for everyone; stealth mode and video neutralization are included from day one, not gated behind a paid plan. No account, no sign-up, no time limit — free forever.

**Key features (5):**
1. Stealth anti-detection — evades anti-adblock walls
2. Universal video-ad neutralization — no pre-roll, no re-buffering, no quality drop
3. 190 network rules + CSS cosmetic filtering + per-site whitelist (4 pause modes)
4. Zero data collection — no telemetry, no tracking, no remote logging
5. 100% free, featherlight, 15 languages, MV3-native

Ad Blocker, Browser Extension, Privacy & Security, Anti-Tracking, Internet Security
