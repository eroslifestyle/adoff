프랑스 캐치업 TV용 광고 차단기: france.tv, TF1, 6play

AdOff는 대부분의 경우, 브라우저에서 프랑스어 캐치업 TV 플랫폼의 프리롤 및 미드롤 광고를 제거합니다. 이 확장 프로그램은 플레이어가 요청하는 Google IMA 광고 SDK에 대한 로컬 스텁을 대신 삽입하여, 광고 브레이크를 재생하는 대신 즉시 콘텐츠 재생을 재개합니다. 이 기능은 플랫폼이 표준 SDK 통합을 사용하는 데스크톱 웹 플레이어에서 작동합니다.

프랑스 서비스 포함

프랑스 방송사는 표준 Google IMA SDK를 통해 브라우저 플레이어로 전달되는 동영상 광고를 통해 리플레이 플랫폼을 운영합니다. AdOff는 다음과 같은 항목을 커버합니다:

  • france.tv (france.tv)
  • TF1 (tf1.fr)
  • 6play (6play.fr)
  • M6 (m6.fr)
  • Arte (arte.tv)
  • myCANAL (mycanal.fr)

플레이어 중심 접근 방식, 모글 잡기식 접근 방식이 아님

각 방송사의 광고 포맷을 하나씩 따라다니는 대신, AdOff는 공통 구성 요소인 광고 SDK를 대상으로 합니다. 이 확장 프로그램은 SDK 스크립트 요청을 자체 제공하는 스텁(stub)으로 리디렉션합니다. 이 스텁은 플레이어의 상태 머신(state machine)을 정상 작동하게 유지하며 — 광고 요청을 수락한 후 즉시 콘텐츠 재개 신호를 보내 — 프로그램이 계속 진행되고, 광고 중간 광고는 결코 발생하지 않습니다.

표준 SDK가 나타나는 모든 곳에 적용되는 하나의 메커니즘이, 6개의 다양한 프랑스 플랫폼에서의 커버리지를 유지하기 쉽게 만듭니다.

리플레이 vs 실시간 스트리밍 vs 캐널의 구독 등급

TF1 또는 6play의 스트림을 다시 보기하는 것은 광고가 포함되어 있으므로 무료이며, 이 지점에서 차단 해제가 작동합니다. 실시간 채널과 일부 스포츠는 다른 파이프라인을 사용하므로 결과는 상황에 따라 달라집니다. myCANAL은 서버 측 삽입 방식을 사용하는 유료 구독 등급도 제공합니다. 이러한 스트림은 광고를 영상 자체에 삽입하므로, 확장 프로그램은 의도적으로 개입하지 않아 플레이어가 정상 작동하도록 유지합니다.

플레이어 주변의 페이지 수준 필터링

비디오 레이어 외에도 AdOff는 광고 및 추적 도메인에 대해 190개의 정적 네트워크 규칙을 적용하고 코스메틱 CSS/DOM 필터를 적용합니다. france.tv 또는 TF1 페이지에서는 인터페이스에서 프로모 배너와 오버레이 박스를 제거하여 재생을 시작하기 전에도 페이지를 더 가볍게 만듭니다.

명확하게 제시된 한계

  • SSAI: 광고가 서버 측에서 스트림에 통합된 후에는 스텁이 더 이상 적용되지 않습니다.
  • 데스크톱 브라우저 전용: TF1 또는 6play 모바일 앱 및 스마트 TV 앱은 대상에서 제외됩니다.
  • 일부 실시간 방송 및 스포츠는 다른 전달 방식을 사용합니다.
  • 방송사가 플레이어를 자주 업데이트하므로, 커버리지는 시간이 지나도 유지되며, 결코 고정되지 않습니다.

무료, 계정 필요 없음, 5개 브라우저 지원

AdOff는 TF1 리플레이에서 광고를 제거합니까?

대부분의 경우에 해당됩니다: TF1 웹 플레이어는 Google IMA SDK를 통해 광고를 로드하며, AdOff는 해당 SDK를 즉시 프로그램을 재개하는 스텁(stub)으로 대체합니다. TF1이 다른 삽입 기법을 사용하는 경우, 지원 범위는 다를 수 있습니다.

6play를 광고 없이 무료로 시청할 수 있나요?

AdOff는 6play 웹 플레이어의 광고 SDK를 무력화하는 무료 브라우저 확장 프로그램으로, 광고 중간에 삽입되는 광고가 재생되지 않도록 합니다. 6play Max는 별도의 유료 서비스이며, AdOff는 사용자의 계정에 영향을 주지 않으며 자체 유료 요금제도 없습니다.

myCANAL은 어떤가요?

myCANAL은 브라우저 플레이어가 표준 IMA SDK를 사용하는 경우에 지원됩니다. 채널의 구독 스트림 중 서버 측 광고 삽입이 적용된 스트림은 의도적으로 제외되어 플레이어가 올바르게 작동하도록 합니다.

프랑스 TV 앱이나 스마트 TV에서 작동하나요?

아니요. AdOff는 데스크톱 브라우저에서만 작동합니다. 모바일 앱, 스마트 TV 앱 및 스트리밍 스틱은 해당 범위를 벗어납니다.

아르테도 포함되어 있나요?

네, arte.tv는 보호 대상 그룹에 포함됩니다. Arte 웹 플레이어가 표준 광고 SDK를 요청할 때도 동일한 스텁 메커니즘이 적용되며, 대부분의 경우 광고 중단 없이 콘텐츠 재생이 재개됩니다.
