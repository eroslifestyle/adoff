填补空缺的 Firefox 广告拦截器

Firefox 内置保护可拦截许多跟踪器和第三方 Cookie，但无法中和视频广告、不能可靠突破反广告拦截墙，也遮不住所有残留广告元素。AdOff 是面向 Firefox（128.0 及以上）的 Manifest V3 扩展，在浏览器自身防御之上增加网络广告拦截、外观过滤、视频广告中和与隐身反检测。

Firefox 已经做到的

Firefox 自带内容拦截功能，开箱即可过滤相当一部分跟踪器和第三方 Cookie。对于日常浏览，这已经清除了不少干扰，许多用户仅凭它就已满足。

专用拦截器仍然有用武之地的地方

Firefox 的原生保护不在 SDK 层面中和视频广告，因此流媒体和视频密集网站上仍可能出现贴片广告。它们也不运行隐身层，所以有些网站仍能检测到拦截并展示反广告拦截墙。而且漏过网络过滤的广告元素仍会显示在页面上。

AdOff 恰好补上这些层：对广告请求的网络拦截、隐藏 DOM 中残留广告元素的元素级过滤、SDK 级别的视频广告中和，以及防止反广告拦截墙触发的隐身模式。

AdOff 在 Firefox 上如何工作

适用于 Firefox 的 AdOff 是一款 Manifest V3 扩展，与 Chromium 版本使用同一引擎：声明式网络规则拦截发往广告网络的请求，样式表隐藏页面上的广告残留，而一个小的页面内层可中和视频广告 SDK，让播放器直接进入内容。

有一个值得了解的技术细节：Firefox 不像 Chromium 浏览器那样支持直接向页面的主世界注入脚本。AdOff 提供了专门的注入器（stealth-injector.js）来弥合这一差距，因此隐身反检测层在 Firefox 上同样有效——与你在其他浏览器中得到的保护相同，并适配了 Firefox 的实际工作方式。

在 Firefox 上安装 AdOff

Download adoff-firefox.zip from adoff.app, extract it, open about:debugging#/runtime/this-firefox and load the extension with "Load Temporary Add-on". The full step-by-step guide, with screenshots, is on the install page. AdOff requires Firefox 128.0 or later; make sure you pick the Firefox ZIP, not the Chromium one.

与单用 Firefox 相比有何不同

只用 Firefox，你保留了浏览器原生的跟踪器防护，但看到的页面仍是网站想给你看的页面：视频播放器照播广告段，一些网站把内容藏在反广告拦截警告后面，横幅残留也躲过了网络过滤。加上 AdOff 后，广告请求在离开浏览器前就被切断，可见的残留被从页面中隐藏，视频播放器直接跳到正片，隐身层让这一切悄无声息。浏览器还是你熟悉的那个 Firefox——同样的界面、同样的设置、同样的速度感——只是渲染出的页面更干净。

常见问题

Firefox 需要广告拦截器吗？

Firefox 默认拦截大量跟踪器，但拦不住视频广告或反广告拦截墙，部分广告元素仍会漏过。AdOff 在此之上补上这些层面。

如何在 Firefox 上安装 AdOff？

从 adoff.app 下载 adoff-firefox.zip，解压后在 about:debugging 中通过“临时载入附加组件”加载。完整教程见安装页面。

支持哪些 Firefox 版本？

AdOff 要求 Firefox 128.0 或更高版本。这是一款基于 Firefox 128+ 支持的标准 WebExtension API 构建的 Manifest V3 扩展。

适用于 Firefox 的 AdOff 能在 Android 上使用吗？

不能。Firefox 版仅面向桌面版 Firefox。目前没有 Android 版扩展。
