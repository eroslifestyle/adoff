以玩家为中心的方法，而非“打地鼠”式应对

AdOff 并非逐一应对各广播公司的广告格式，而是直击其共用组件：广告 SDK。该扩展程序会将 SDK 脚本的请求重定向至其内置的占位脚本。该占位脚本可维持播放器状态机的正常运行——它会确认广告请求并立即发出恢复内容播放的信号，从而确保节目继续播放，广告插播从未真正发生。

一种机制，应用于标准 SDK 出现的任何位置，使得在六种不同的法国平台上维持覆盖成为可能。

回放 vs 实时直播 vs Canal+ 订阅等级

TF1 或 6play 上的回看直播流是免费的，因为其嵌入了广告，而广告屏蔽功能正是在此处生效。直播频道及部分体育赛事使用不同的传输管道，因此效果各不相同。myCANAL 还提供付费订阅服务，采用服务器端广告插入方式：此类直播流会将广告直接拼接到视频内容中，而本扩展程序则刻意保持不干预，以确保播放器正常运行。

常见问题

AdOff 是否能移除 TF1 回看中的广告？

在大多数情况下是的：TF1 网页播放器通过 Google IMA SDK 加载广告，而 AdOff 会将该 SDK 替换为一个占位符，从而立即恢复节目播放。在 TF1 使用其他插入方式的情况下，覆盖效果可能有所不同。

我能否免费观看无广告的6play？

AdOff 是一款免费的浏览器扩展程序，可中和 6play 网页播放器中的广告 SDK，从而避免插播广告。6play Max 是另一款独立的付费产品；AdOff 不会影响您的账户，且自身并无付费版本。

那 myCANAL 呢？

myCANAL 在其浏览器播放器使用标准 IMA SDK 时受支持。由于 Canal 的订阅流采用服务器端广告插入，为确保播放器正常运行，此类流被明确排除在外。

它是否适用于 FranceTV 应用或智能电视？

不。AdOff 仅适用于桌面浏览器。移动应用、智能电视应用及流媒体棒均不在其覆盖范围内。

Arte 也包含在内吗？

是的，artef.tv 属于受覆盖范围内的网站。当 Arte 网页播放器请求标准广告 SDK 时，同样会启用占位符机制，在大多数情况下可恢复播放内容而无需中断。
