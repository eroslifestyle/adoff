什么是广告拦截扩展，它如何工作

广告拦截扩展是安装在浏览器里的小型附加组件，过滤你访问页面上的加载内容：广告请求被取消，页面中残留的广告元素被隐藏，一些拦截器还会处理视频广告。本页解释这类扩展如何工作、它安装了什么、请求哪些权限及其原因，以及 Manifest V3 带来的变化。

扩展如何拦截广告

在底层，广告拦截扩展工作在两个层面。网络层面，它查询一份规则列表——匹配已知广告和跟踪器地址的模式——并在任何数据下载前取消匹配的请求。页面层面，它检查渲染后的文档，用样式隐藏残留的广告容器，不留下空盒子。像 AdOff 这样的扩展结合了两个层面，更好的还会加上按站点的上下文：视频广告处理和反反拦截检查的防护。

安装一个

安装只需一分钟。你可以从浏览器的附加组件商店安装——Chrome Web Store、Firefox Add-ons、Edge Add-ons 商店或 Safari 的对应商店——或者在提供时直接从开发者网站下载安装包。安装后，扩展通常会在地址栏附近显示一个图标；从那里可以查看拦截了什么、在特定网站上暂停，或完全关闭。开始拦截通常不需要任何配置。

权限：为什么这么多

广告拦截器会请求宽泛的权限，原因是结构性的：它必须能够读取并过滤你可能访问的每个网站上的页面，并检查这些页面发出的请求。权限本身并不是危险信号——没有它，扩展根本无法工作。重要的是开发者用这个访问权做什么。值得信赖的拦截器会明确声明：不收集浏览数据，不向服务器发送任何内容。安装任何东西之前，请先查看隐私政策。

扩展 vs 独立应用

独立的广告拦截应用在浏览器之外工作：它可能过滤全系统流量或运行自己的本地代理，覆盖浏览器之外的部分应用，代价是更繁琐的设置和对系统更深的介入。扩展则完全活在浏览器内：更轻量、一分钟装好、经过附加组件商店审核，并且浏览器走到哪里它就工作到哪里——包括其他操作系统。如果你的广告大多出现在网页上，扩展是更简单也更安全的选择；原生应用里的广告无论如何都超出了它的能力范围。

Manifest V3 改变了什么

Chrome 的 Manifest V3 是这个品类多年来最大的平台变革。它用一个声明式引擎取代了让扩展拦截并改写每个网络请求的 API：拦截器预先声明规则，由浏览器执行。做得好，拦截依然有效——AdOff 是 MV3 原生扩展，在新规则下依然完整工作。而基于旧 API 的扩展在 Chrome 上失去了大部分能力。Firefox 和 Safari 也在向类似模式靠拢，因此 MV3 就绪度已成为现代广告拦截器的实际试金石。
