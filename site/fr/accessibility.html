Déclaration d'accessibilité

Objectif de conformité : WCAG 2.2 niveau AA (auto-évaluation) · Normes : W3C WCAG 2.2, EN 301 549 · Dernière révision : 11 juin 2026

AdOff s'engage à rendre adoff.app utilisable par tous, y compris les personnes qui dépendent de technologies d'assistance. L'accessibilité correspond à ce en quoi nous croyons déjà : un produit doit fonctionner discrètement et respecter ses utilisateurs, tous.

État de conformité

Notre objectif est le respect des Web Content Accessibility Guidelines (WCAG) 2.2, niveau AA. Nous estimons que les pages principales de ce site (accueil, installation, support, tarifs, pages légales) sont actuellement conformes à ce niveau. Il s'agit d'une auto-évaluation : il n'existe pas de certification WCAG officielle par un tiers, et nous préférons expliquer honnêtement comment nous testons plutôt que d'afficher un badge acheté.

Pour les visiteurs de l'Union européenne : la conformité WCAG 2.2 AA couvre aussi les exigences web de la norme harmonisée EN 301 549, référencée par l'European Accessibility Act.

Ce que nous faisons

  • Contraste des couleurs : la palette du site est vérifiée selon les ratios WCAG AA (4,5:1 pour le texte), y compris boutons, pied de page et textes secondaires.
  • Navigation au clavier : toutes les fonctionnalités sont accessibles au clavier, avec des indicateurs de focus visibles et un lien « aller au contenu » sur chaque page.
  • Structure sémantique : repères HTML natifs, formulaires étiquetés, textes alternatifs sur les images, attribut lang correct sur les 15 versions linguistiques.
  • Mouvement réduit : toutes les animations sont désactivées si votre système demande la réduction des animations.
  • Pas d'overlay d'accessibilité : nous corrigeons les problèmes dans le code au lieu de les masquer avec des widgets tiers.

Comment nous testons

Audits automatisés avec axe-core (règles WCAG 2.x A/AA) sur les pages principales, plus des vérifications manuelles : navigation au clavier seul, zoom jusqu'à 200 % et vérification du contraste de chaque token de couleur. Les audits sont répétés à chaque évolution du design system.

Limites connues

  • Les espaces compte et admin (derrière connexion) n'ont pas encore été entièrement audités.
  • L'interface de l'extension navigateur (popup, options, onboarding) a passé le même audit automatisé WCAG 2.x A/AA depuis la version 3.5.7 ; les builds mis à jour arrivent dans les stores au fil des validations.

Retour d'information

Si vous rencontrez un obstacle d'accessibilité sur ce site ou dans l'extension AdOff, signalez-le via le formulaire de support. Décrivez la page et le problème ; nous visons une réponse sous quelques jours ouvrés, et les signalements d'accessibilité sont traités comme des bugs, pas comme des suggestions.
