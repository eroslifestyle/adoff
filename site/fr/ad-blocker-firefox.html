Un bloqueur de publicités pour Firefox qui comble les manques

Les protections intégrées de Firefox bloquent de nombreux traqueurs et cookies tiers, mais elles ne neutralisent pas les publicités vidéo, ne viennent pas à bout de manière fiable des murs anti-adblock et ne masquent pas chaque résidu publicitaire. AdOff est une extension Manifest V3 pour Firefox (version 128.0 ou ultérieure) qui ajoute le blocage réseau des publicités, le filtrage cosmétique, la neutralisation des publicités vidéo et le stealth anti-détection par-dessus les défenses du navigateur.

Ce que fait déjà Firefox

Firefox est livré avec un blocage de contenu intégré, qui élimine d'emblée une bonne part des traqueurs et des cookies tiers. Pour la navigation quotidienne, cela supprime déjà beaucoup de bruit, et beaucoup d'utilisateurs s'en contentent.

Où un bloqueur dédié reste utile

Les protections natives de Firefox ne neutralisent pas les publicités vidéo au niveau du SDK : les pré-roll peuvent donc encore apparaître sur les sites de streaming et riches en vidéo. Elles n'exécutent pas non plus de couche stealth, si bien que certains sites détectent toujours le blocage et affichent des murs anti-adblock. Et les éléments publicitaires qui échappent aux filtres réseau restent visibles sur la page.

AdOff ajoute précisément ces couches : blocage réseau des requêtes publicitaires, filtrage cosmétique qui masque les résidus publicitaires dans le DOM, neutralisation des publicités vidéo au niveau du SDK et un mode stealth qui empêche les murs anti-adblock de se déclencher.

Comment fonctionne AdOff sur Firefox

AdOff pour Firefox est une extension Manifest V3 bâtie sur le même moteur que la version Chromium : des règles réseau déclaratives bloquent les requêtes vers les régies publicitaires, une feuille de style masque les résidus publicitaires cosmétiques, et une petite couche dans la page neutralise les SDK de publicités vidéo pour que les lecteurs reviennent directement au contenu.

Un détail technique mérite d'être connu : Firefox ne permet pas d'injecter des scripts directement dans le monde principal de la page comme le font les navigateurs Chromium. AdOff fournit un injecteur dédié (stealth-injector.js) qui comble cet écart, si bien que la couche stealth anti-détection fonctionne aussi sur Firefox — la même protection qu'ailleurs, adaptée au fonctionnement réel de Firefox.

Installer AdOff sur Firefox

Download adoff-firefox.zip from adoff.app, extract it, open about:debugging#/runtime/this-firefox and load the extension with "Load Temporary Add-on". The full step-by-step guide, with screenshots, is on the install page. AdOff requires Firefox 128.0 or later; make sure you pick the Firefox ZIP, not the Chromium one.

Ce qui change par rapport à Firefox seul

Avec Firefox seul, vous conservez la protection native contre les traqueurs du navigateur, mais la page que vous voyez reste celle que le site veut vous montrer : les lecteurs vidéo diffusent leurs coupures publicitaires, certains sites conditionnent l'accès au contenu à des avertissements anti-adblock, et les résidus de bannières survivent aux filtres réseau. Avec AdOff par-dessus, les requêtes publicitaires sont coupées avant de quitter le navigateur, les résidus visibles sont masqués de la page, les lecteurs vidéo passent directement au contenu, et la couche stealth garde le tout silencieux. Le navigateur reste le Firefox que vous connaissez — même interface, mêmes réglages, même sensation de rapidité — les pages affichées sont simplement plus propres.

Foire aux questions

Firefox a-t-il besoin d'un bloqueur de publicités ?

Firefox bloque de nombreux traqueurs par défaut, mais pas les publicités vidéo ni les murs anti-adblock, et certains éléments publicitaires passent encore. AdOff ajoute ces couches par-dessus.

Comment installer AdOff sur Firefox ?

Téléchargez adoff-firefox.zip depuis adoff.app, extrayez-le et chargez-le depuis about:debugging avec « Load Temporary Add-on ». Le tutoriel complet se trouve sur la page d'installation.

Quelles versions de Firefox sont prises en charge ?

AdOff nécessite Firefox 128.0 ou ultérieur. C'est une extension Manifest V3 bâtie sur les API WebExtension standard prises en charge par Firefox 128+.

AdOff pour Firefox fonctionne-t-il sur Android ?

Non. La version Firefox d'AdOff cible uniquement Firefox sur ordinateur. Il n'existe pas actuellement de version Android de l'extension.
