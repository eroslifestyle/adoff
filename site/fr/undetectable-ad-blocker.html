Le bloqueur indétectable

— Eros

Un bloqueur indétectable supprime les annonces et masque le fait qu'il l'ait fait. Les bloqueurs réguliers laissent des traces mesurables — emplacements publicitaires vides, demandes bloquées — que les scripts anti-adblock détectent. Le mode Stealth d'AdOff usurpe ces signaux pour que les sites ne voient rien d'inhabituel.

Comment les sites Web détectent les bloqueurs de pub

Les systèmes anti-adblock plantent des éléments publicitaires appâts et vérifient s'ils sont cachés, envoient des demandes de test aux serveurs publicitaires et vérifient s'ils sont bloqués, et sondent les variables JavaScript liées aux annonces. Un bloqueur normal réagit à tous ces cas d'une manière que la page peut mesurer.

Une fois détecté, le site peut cacher son contenu derrière un mur, afficher un message d'avertissement, ou dégrader discrètement votre expérience. Vous avez bloqué les annonces, mais le site sait — et riposte.

Ce qui rend un bloqueur indétectable

Être indétectable signifie passer ces sondes comme si aucun bloqueur n'était présent : l'élément appât semble visible, les demandes de test semblent répondues, les variables attendues existent. AdOff opère dans le contexte d'exécution principal de la page et usurpe les éléments d'appât, intercepte les récupérations de détection et masque les variables sur lesquelles s'appuie l'anti-adblock.

Le résultat : les annonces sont supprimées au niveau réseau et cosmétique, mais les sondes reviennent normales. Pas de mur, pas d'avertissement.
