YouTube Shortsでの広告ブロック：フィード広告はブロック、動画広告はブロックしない

YouTube Shortsの広告は、縦長動画をスクロールする際に動画の間に挿入されるネイティブフィードユニットであり、プレイヤー内での事前ロールではありません。これらはページの要素であり、スケジュールされたプレイヤーのブレイクではないため、視覚的フィルタリング（CSSおよびDOMルール）によって広告コンテナを非表示にします。カバー範囲は実在しますが、フォーマットが変更された場合に限界があります。

ショーツ広告は、動画広告とは異なる種類のものです。

通常の動画の前にプレロールが再生される場合、プレイヤーはそれをリクエストして再生した後、あなたの動画を再開します。一方、ショーツでは仕組みが異なります。フィードをスワイプしている際、そのフィード内の一部のアイテムは単に広告です。それらはショーツのように見え、ショーツのようにスクロールし、同じフィードのレスポンスに含まれています——プレイヤーが別途スケジュールする広告ブロックではありません。

この違いが、ブロッキング戦略全体を決定します。プレイヤー単位のツール（スケジュール削除、再生速度の加速）は、ここでは何も実行できません。なぜなら、ブレイクは決してスケジュールされないからです。

なぜ「化粧フィルタリング」がフィード広告に最適なツールなのか

フィード広告とは、予測可能な構造を持つページ要素です。具体的には、コンテナ、スポンサー表示などのラベル、および広告ユニット固有のレンダラー コンポーネントが含まれます。コスメティックフィルタリングは、これらの構造をCSSセレクタとDOMルールで一致させ、広告コンテナが描画される前またはその際に非表示にすることで、フィード項目が一切表示されないようにします。

AdOffは、動画プラットフォームのショートフォームページに対して、独自の cosmetic セレクターを適用します。これは、すべてのサイトで実行される汎用広告セレクターに加えて行われます。同じセレクターは、注入された CSS と DOM スキャン層の両方で適用されるため、一方の方法で非表示にされた要素は、もう一方の方法でも削除されます。詳細は AdOff の仕組み をご覧ください。

フィードにおける視覚的フィルタリングのできることとできないこと

できること：構造がセレクターに一致する広告ユニットを非表示にし、それに付随する「広告」ラベルやオーバーレイタイルを削除します。固定されたフォーマットでは、これは信頼性が高く、コストもかかりません——待たされることも、カウントダウンを待つこともなく、広告はスワイプストリームに一切現れません。

できないこと：まだリリースされていないフォーマットのカバーを保証すること。プラットフォームがフィード広告ユニットの構造を変更した場合、セレクタは更新されるまでマッチしなくなります。これは、すべての視覚的（コスメティック）なアプローチに共通する正直な制限であり、特定の広告ブロッカーに限らず、すべての広告ブロッカーに適用されます。

ネットワークレベルのブロッキングのみでは、ショート動画（Shorts）をカバーできない理由

DNSレベルまたはネットワークレベルでの広告ネットワークのブロッキング（AndroidでのDNSベースのブロッキングを参照）は、既知の広告サーバーへのリクエストを停止します。しかし、動画プラットフォーム上のフィード広告は、多くの場合、コンテンツフィード自体と同じドメインおよびリクエストを通じて配信されるため、ネットワークフィルターでそれらを削除すると、フィード全体が壊れてしまいます。そのため、実用的な作業はブラウザ内でDOMレベルで行われ、広告ユニットとコンテンツユニットを構造によって区別できるようになっています。

ショート動画の広告を実際的にブロックする方法

セットアップは、その他の動画プラットフォームの場合と同じです：短形の cosmetic セレクターを含むブラウザ拡張機能をインストールし、保護を有効のままにし、CSS および DOM レイヤーに処理を任せます——動画ごとに設定する必要はありません。AdOff は、アカウント不要で、Chrome、Firefox、Safari、Edge、Opera でこれを無料で提供します。

広告ユニットがすり抜けていることに気づいた場合、通常はフォーマットが変更されたことを意味します。修正はセレクターの更新とともに提供されます。この状況の詳細な背景については、広告ブロッカーが機能しなくなった場合の対処法をご覧ください。

ショート広告がブロッキングの全体像にどのように組み込まれるか

フィード広告は、プラットフォーム上の4種類の広告タイプの1つであり、他の広告タイプはプレイヤー内に表示されます。完全なセットアップには、2つのストーリーが必要です。すなわち、プリロールおよびミドルール用のスケジューリングレイヤーによるブロッキングと、フィードユニットおよびオーバーレイ用の視覚的フィルタリングです。これらのレイヤーがどのように統合され、各プラットフォームがどこに位置するかを包括的に示した内容はストリーミング広告ブロッキング explainedに、プラットフォーム固有の詳細はYouTube広告ブロッカー ガイドに記載されています。

よくある質問

YouTube Shortsの広告は、通常の動画広告と同じですか？

いいえ。ショーツ広告は、縦方向の動画をスクロールする際に動画の間に挿入されるネイティブフィードユニットです。通常の動画広告は、プレイヤー内の所定のタイミングで再生されるブレイクです。配信方法が異なるため、ブロッキング手法も異なります。

ショート動画の広告は、どのようにブロックされているのですか？

cosmeticフィルタリングを通じて：フィード内の広告コンテナの構造を認識するCSSおよびDOMルールを適用し、表示される前にそれらを非表示にします。動画広告のスケジューリングレイヤーは、フィード内に広告ブレイクがスケジュールされていないため、何も対象としません。

すべてのショート動画広告を非表示にできますか？

現在のほとんどのフォーマットに対応していますが、保証は付きません。つまり、プラットフォームが新しいフィード広告の構造を導入した場合、セレクタは一致しなくなり、更新されるまで機能しません。視覚的なカバー範囲は、既存のフォーマットに従います。

DNSレベルの広告ブロッキングでは、Shortsの広告を削除できないのはなぜですか？

フィード広告は通常、コンテンツフィード自体と同じドメインを通じて配信されるためです。これらのリクエストをブロックするネットワークフィルターを使用すると、フィード全体が機能しなくなります。ページ構造によって広告とコンテンツを分離できるのは、ブラウザ内でのフィルタリングのみです。

AdOffはショート動画の広告をブロックしますか？また、無料ですか？

AdOffは、Chrome、Firefox、Safari、Edge、Operaで無料の保護機能として短形の視覚的セレクターを適用します。アカウントは不要です。視覚的フィルタリングはすべて同様に、固定された結果を保証するのではなく、現在の広告フォーマットに応じてカバレッジが変化します。
