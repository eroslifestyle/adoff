Manifest V3 विज्ञापन रोधक जो अभी भी काम करता है

— Eros

Manifest V3 ने बदल दिया कि Chrome विस्तार अनुरोधों को कैसे अवरुद्ध करते हैं, पुरानी प्रणाली के लिए निर्मित अवरोधकों को कमजोर करते हुए। AdOff जैसा मूल Manifest V3 विज्ञापन रोधक के चारों ओर डिज़ाइन किया गया है declarativeNetRequest नियम जमीन से ऊपर, इसलिए यह विज्ञापनों को पूरी तरह से और कुशलतापूर्वक ब्लॉक करता रहता है।

Manifest V3 ने क्या बदला

Chrome की Manifest V3 ने पुरानी गतिशील अनुरोध-अवरोधन API को एक घोषणात्मक के साथ प्रतिस्थापित किया और नियमों को कैसे कार्य करता है यह सीमित किया। पुरानी पद्धति पर निर्मित अवरोधकों को फिर से लिखना पड़ा, और कुछ ने क्षमता खो दी या चरणबद्ध किए गए, यही कारण है कि दीर्घकालीन उपयोगकर्ताओं को विज्ञापन वापस आते हुए ध्यान दिया।

क्यों मूल Manifest V3 अवरोधक मजबूत रहते हैं

Manifest V3 के लिए डिज़ाइन किया गया एक अवरोधक घोषणात्मक नियम इंजन का उपयोग करता है जिस तरह Chrome अब इरादा रखता है, सामग्री-स्क्रिप्ट सौंदर्य फ़िल्टरिंग और मुख्य-विश्व स्क्रिप्टिंग के साथ उन्नत मामलों के लिए। AdOff मूल Manifest V3 के लिए निर्मित था: नेटवर्क नियम, सौंदर्य छिपाना, वीडियो विज्ञापन तटस्थता और गोपनीयता सभी नई मॉडल के भीतर काम करती हैं।

स्थापन से पहले क्या जाँचें

सुनिश्चित करें कि अवरोधक स्पष्ट रूप से Manifest V3 का समर्थन करता है और सक्रिय रूप से बनाए रखा जाता है। AdOff Chrome, Edge, Opera, Brave के साथ-साथ Firefox और Safari बिल्ड पर Manifest V3-मूल है।

अक्सर पूछे जाने वाले प्रश्न

क्या Manifest V3 ने विज्ञापन अवरोधकों को मार दिया?

इसने पुरानी प्रणाली के लिए निर्मित अवरोधकों को कमजोर किया, लेकिन AdOff जैसे मूल Manifest V3 अवरोधक नए घोषणात्मक नियमों का उपयोग करके पूरी तरह से ब्लॉक करते रहते हैं।

सबसे अच्छा Manifest V3 विज्ञापन रोधक कौन सा है?

एक मजबूत विकल्प नेटवर्क ब्लॉकिंग, सौंदर्य फ़िल्टरिंग और गोपनीयता के साथ निर्मित एक है। AdOff इसमें फिट बैठता है और हल्का है।

क्या मेरा पुराना विज्ञापन अवरोधक काम करना बंद कर देगा?

कुछ पुराने अवरोधकों ने Manifest V3 के तहत क्षमता खो दी। एक मूल Manifest V3 अवरोधक उस समस्या से बचता है।
