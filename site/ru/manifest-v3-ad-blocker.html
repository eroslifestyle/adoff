Manifest V3 изменил способ, которым расширения Chrome блокируют запросы, ослабляя блокировщики, созданные для старой системы. Что изменилось в Manifest V3

Manifest V3 Chrome заменил старый динамический API блокировки запросов на декларативный и ограничил, как работают правила. Блокировщики, созданные на основе старого подхода, пришлось переписывать, и некоторые потеряли функциональность или были прекращены, вот почему долгие пользователи заметили, что объявления вернулись.

Почему нативные блокировщики MV3 остаются сильными

Блокировщик, разработанный для Manifest V3, использует декларативный движок правил так, как Chrome теперь предполагает, в сочетании с косметической фильтрацией контент-скрипта и основным скриптом мира для продвинутых случаев. AdOff был построен MV3-нативным: правила сети, косметическое скрывание, нейтрализация видео-объявлений и stealth все работают в новой модели.
